# POTENZIALE 1.2.1

## Nuovo: Task quotidiane automatiche
- Ogni giorno viene generato un piano di 3 task diverso, in modo deterministico.
- Le task coprono a rotazione Corpo, Crescita, Disciplina, Economia, Ambiente, Carriera e Relazioni.
- La schermata Oggi mostra anche un’anteprima delle task di domani.
- Le task generate automaticamente restano salvate e possono essere completate normalmente.
- Le task aggiunte manualmente continuano a funzionare senza interferire con il piano quotidiano.
- Compatibilità mantenuta con i dati già presenti in POTENZIALE 1.2.

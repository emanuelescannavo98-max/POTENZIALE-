# POTENZIALE 1.3.0

## Obiettivo
Trasformare POTENZIALE da semplice tracker a sistema personale adattivo.

## Novità
- Motore giornaliero adattivo: le task automatiche cambiano in base a continuità, energia, stress e pilastri più deboli.
- Modalità RIACCENSIONE / STANDARD / ESPANSIONE.
- Momentum reale: giorni consecutivi con almeno una task completata.
- Potenziale Score settimanale basato su continuità + stato dei pilastri.
- Vista progressi con andamento degli ultimi 7 giorni.
- Check-in collegato direttamente alla generazione delle task successive.
- Economia con target mensili modificabili e saldo dei movimenti.
- Migrazione automatica da POTENZIALE 1.2 / 1.2.1: i dati locali vengono preservati.
- Backup con versione applicazione e ripristino compatibile.
- Service Worker aggiornato alla cache 1.3.0.

## Regola fondamentale
La 1.3 non sostituisce il lavoro fatto: aggiunge un livello adattivo sopra la struttura esistente.
